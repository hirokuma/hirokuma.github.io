## アップデートしたい

このリポジトリはいささか古い時点で更新が止まっている。
せめて`Cargo.toml`だけでも新しくしておきたい。  
が、元々のリポジトリで既にwarningが残ったりしていて、さすがになんだかなぁ、と思って多少更新した。
BOLT12/Offer関連の仕様をよく知らずdeprecatedのメソッドをうまく変更できそうにないので、ガサッと削除した。

* [hirokuma/ldk-sample - Rust Bitcoin Forge](https://git.rust-bitcoin.org/hirokuma/ldk-sample)

## 動かす

今回も[Nigiri](https://github.com/vulpemventures/nigiri)を使った。

```bash
nigiri start --ln
```

Nigiriの`rpcuser`と`rpcpassword`を指定し、ポート番号は`9735`を使われているので適当に指定。
コマンド入力待ちになる。

```shell
$ cargo run admin1:123@127.0.0.1:18443 ./data 19735 regtest
LDK startup successful. Enter "help" to view available commands. Press Ctrl-D to quit.
LDK logs are available at <your-supplied-ldk-data-dir-path>/.ldk/logs
Local Node ID is 03f900458e1919d89622f29c993b961656b81bdeea196554ab440300e5ec8ec9e8.
>
```

`connectpeer`をしてみよう。  
まずはNigiriの方のLNDノードを知る。

```shell
$ nigiri lnd getinfo | jq .identity_pubkey | jq
"02b60165f044978996617c33d3978e9f2c39c3fe09721e0111ee4fa7332b68528b"
```

ldk-sample側に打ち込む。

```log
> connectpeer 02b60165f044978996617c33d3978e9f2c39c3fe09721e0111ee4fa7332b68528b@127.0.0.1:9735
SUCCESS: connected to peer 02b60165f044978996617c33d3978e9f2c39c3fe09721e0111ee4fa7332b68528b
```

Nigiri側で`listpeers`すると、ldk-sampleの開始時に出力されたnode_idと一致していることがわかる。

```shell
$ nigiri lnd listpeers | jq .peers[0].pub_key
"03f900458e1919d89622f29c993b961656b81bdeea196554ab440300e5ec8ec9e8"
```
