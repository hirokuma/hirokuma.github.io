しばしばRustで`Vec<u8>`やら`[u8; 32]`などを扱う。  
単独なら`hex::encode()`でデバッグ出力してもよいが、`struct`だといちいち書くのが面倒。  
ならば、と`Display`を使ってがんばっていたのだが・・・気力が尽きた。

デバッグ出力なので整形は特にせず、フィールド名と値が分かれば十分なのだ。
それなのに`Display`に対応するために全部のフィールドをいちいち`write!()`しないといかんし、`Option<T>`がまざっていたらそれも対応を考えないといかんし、ひたすら面倒だ。

気力がなえたのでAIに聞いてみると、そういうことができるマクロがあるそうだ。
最初に聞いておけばよかった。

## educe

```toml
[dependencies]
educe = "0.8.1"
hex = "0.4.3"
```

```rust
use std::fmt;
use educe::Educe;

#[derive(Educe)]
#[educe(Debug)]
struct Abc {
    a: i32,
    b: String,
    #[educe(Debug(method(hex_vec)))]
    c: Vec<u8>,
    #[educe(Debug(method(hex_4)))]
    d: [u8; 4],
}

fn main() {
    let a = Abc{ a: -123, b: "Good Morning".to_string(), c: vec![1, 2, 3, 4, 5], d: [10, 11, 12, 13]};
    println!("{:?}", a);
}

fn hex_vec(v: &Vec<u8>, f: &mut fmt::Formatter<'_>) -> fmt::Result {
    write!(f, "<0x{}>", hex::encode(v))
}

fn hex_4(v: &[u8; 4], f: &mut fmt::Formatter<'_>) -> fmt::Result {
    write!(f, "[0x{}]", hex::encode(v))
}
```

結果

```log
Abc { a: -123, b: "Good Morning", c: <0x0102030405>, d: [0x0a0b0c0d] }
```

ああ、こういうのでいいんだよ・・・。

ちなみにeduceがない場合はこうなる。まあ場合によりけりですな。

```log
Abc { a: -123, b: "Good Morning", c: [1, 2, 3, 4, 5], d: [10, 11, 12, 13] }
```

中の表現を変更しなくて良いなら引数を`&[u8]`で受けてまとめてしまえばよかろう。

```rust
fn hex_vec(v: &[u8], f: &mut fmt::Formatter<'_>) -> fmt::Result {
    write!(f, "<0x{}>", hex::encode(v))
}
```
