人生は唐突だ。  
なので私が急にLDKを使ってみようとしても不自然ではない。

## add

コレを書いている時点ではv0.7.0が最新である。

```bash
cargo add lnd-node
```

開発中のものを使いたければこうか。
いまの時点ではv0.8.0開発中である。

```bash
cargo add --git https://github.com/lightningdevkit/ldk-node ldk-node
```
