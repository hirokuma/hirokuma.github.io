しばしばRustで`Vec<u8>`を`[u8; 32]`に変換する。  
なのに、覚えられない。。。

今回はGeminiに応援を頼みました。

## try_into

```rust
fn main() -> anyhow::Result<()> {
    let vec: Vec<u8> = vec![7; 31];
    let array: [u8; 32] = vec.try_into().map_err(|_| anyhow::anyhow!("not 32 bytes"))?;
    println!("{}", hex::encode(array));
    Ok(())
}
```

エラー値は`Vec<u8>`本体なので、エラーログにしている場合は注意がいるかもしれない。

### try_intoの中身はよくわからん

`try_into()`の中身を見てみたのだが・・・`unsafe`がよくわからん。
`Vec`は先頭から切り取るのではなく長さがイコールでないとダメなのはわかった。

アラインメントうんぬん書いてあるので、値コピーするのではなくメモリアドレスをそのまま使い回すのかな？ 
`read()`しているからそうではないらしい。

```rust
    fn try_from(mut vec: Vec<T, A>) -> Result<[T; N], Vec<T, A>> {
        if vec.len() != N {
            return Err(vec);
        }

        // SAFETY: `.set_len(0)` is always sound.
        unsafe { vec.set_len(0) };

        // SAFETY: A `Vec`'s pointer is always aligned properly, and
        // the alignment the array needs is the same as the items.
        // We checked earlier that we have sufficient items.
        // The items will not double-drop as the `set_len`
        // tells the `Vec` not to also drop them.
        let array = unsafe { ptr::read(vec.as_ptr() as *const [T; N]) };
        Ok(array)
    }
```

### into_boxed_sliceとtry_into

値コピーもなくしたいなら `vec.into_boxed_slice()`してから`try_into()`するとよいらしい。

```rust
fn main() -> anyhow::Result<()> {
    let vec: Vec<u8> = vec![7; 31];

    // let array: [u8; 32] = vec.try_into().map_err(|_| anyhow::anyhow!("not 32 bytes"))?;
    // println!("{}", hex::encode(array));

    let array: Box<[u8; 32]> = vec.into_boxed_slice().try_into().map_err(|_| anyhow::anyhow!("not 32 bytes"))?;
    println!("{}", hex::encode(*array));
    Ok(())
}
```

結局`try_into()`を使うではないか！と思ったが`Box`になるため違うものが使われた。
`boxed_slice_as_array_unchecked()`から先もたどったのだが、`unsafe`がどんどん呼ばれて終わりが見えなかったため止めた。

```rust
    fn try_from(boxed_slice: Box<[T]>) -> Result<Self, Self::Error> {
        if boxed_slice.len() == N {
            Ok(unsafe { boxed_slice_as_array_unchecked(boxed_slice) })
        } else {
            Err(boxed_slice)
        }
    }
```

C言語で作るときはメモリはともかくコピーする時間がもったいない環境が多いので悩むのだが、
Rustだし32バイトくらいならもうコピーしてよいか、という気持ちである。
