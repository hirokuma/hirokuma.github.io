Androidアプリを作ろうと思って準備していたが、そういえばReact NativeやFlutterというものがあったのを思い出した。
React Native環境はWSL2で作ったことがあったので、Flutterもなんとかなるだろうと思ったのだが苦戦している。
主にツール類のアップデートが関係しているようだ。

* [flutter doctor reports Android license status unknown with Android SDK Command-line Tools 23.0 · Issue #191487 · flutter/flutter](https://github.com/flutter/flutter/issues/191487)

今のcmdline-toolsは`23.0.0`が最新のようだ。  
これをURLから直接ダウンロードしてインストールしている。

いまや`sdkmanager`はdeprecatedで、`android sdk`というコマンドを使うようだ。

```shell
$ android sdk list
Installed packages:
  build-tools/37.0.0           37.0.0                 Android SDK Build-Tools 37
  cmake/4.1.2                  4.1.2                  CMake 4.1.2
  cmdline-tools/latest         23.0.0                 Android SDK Command-line Tools (latest)
  emulator                     37.1.11                Android Emulator
  ndk/30.0.16138531            30.0.16138531-rc.3     NDK (Side by side) 30.0.16138531
  platform-tools               37.0.1                 Android SDK Platform-Tools
  platforms/android-36         2.0.0                  Android SDK Platform 36
```

vscodeからflutterのextensionをインストールして`flutter doctor`でチェックしていたのだが、
どれがダメなのかわからんがSDKがダメだと言われ続け、あきらめて[手順](https://docs.flutter.dev/platform-integration/android/setup)にしたがってAndroid Studioを使ってやったあとがこれだ。
雰囲気からすると、build-toolsとか全部インストールしてあればよいだけのような気がする。

そこまでやるとようやくライセンスチェックになるのだが、今の`sdkmanager`というか`android sdk`にはライセンスのコマンドがなくなっているようで`flutter doctor --android-licenses`が失敗する。
cmdline-toolsのバージョンを下げてPATHだけ通しておけばよいかと思ったのだが、それでもダメだった。
`android sdk remove cmdline-tools/latest`で削除してなんとかなった。

```shell
$ android sdk list
Installed packages:
  build-tools/37.0.0           37.0.0                 Android SDK Build-Tools 37      
  cmake/4.1.2                  4.1.2                  CMake 4.1.2                     
  cmdline-tools/22.0           22.0.0                 Android SDK Command-line Tools  
  emulator                     37.1.11                Android Emulator                
  ndk/30.0.16138531            30.0.16138531-rc.3     NDK (Side by side) 30.0.16138531
  platform-tools               37.0.1                 Android SDK Platform-Tools      
  platforms/android-36         2.0.0                  Android SDK Platform 36         
```

これを書いている2026年9月3日にはマージされたようなので、そのうちなんとかなるだろう。

今回動かしたかったサンプルプログラム([bdk-demo](https://github.com/bitcoindevkit/bdk-dart/tree/main/bdk_demo))を`flutter run`すると、
