Flutter 3.47.4を使っている。  
ラジオボタンが使いたくてAIに頼んだところ、出来はしたのだがdeprecatedなプロパティがいくつかある。
[Radio](https://api.flutter.dev/flutter/material/Radio/Radio.html)ではなく[RadioGroup](https://api.flutter.dev/flutter/widgets/RadioGroup-class.html)を使っておけば良さそうだ。
過去の経緯は知らないので`Radio`の書き方を変更すれば良いだけかもしれないが、もういいのだ。

こういう感じ。  
`_hostSelected`は状態変数？で、おそらく`?`付きにして最初は未選択にできるのだと思う。  
ここでは初期値があったので`?`無しで宣言していて、その代わり`newValue!`になっているというところだ。

```dart
enum HostSelection {
  serverA('192.168.0.1'),
  serverB('192.168.0.2');

  const HostSelection(this.host);
  final String host;
}

......

RadioGroup<HostSelection>(
  groupValue: _hostSelected,
  onChanged: (HostSelection? newValue) {
    setState(() {
      _hostSelected = newValue!;
    });
  },
  child: Material(
    type: MaterialType.transparency,
    child: IntrinsicWidth(
      child: Column(
        children: [
          RadioListTile<HostSelection>(
            title: Text(HostSelection.serverA.host),
            value: HostSelection.serverA,
          ),
          RadioListTile<HostSelection>(
            title: Text(HostSelection.serverB.host),
            value: HostSelection.serverB,
          ),
        ],
      ),
    ),
  ),
),
```

`child`の一番上が`Material`なのは、囲まないとエラーが出るからだ。
`ListTile`系だとエラーが出るのかな？ 深く調べていない。

* [ListTile reports an error in debug when wrapped in a colored widget](https://docs.flutter.dev/release/breaking-changes/list-tile-color-warning)

その下が`IntrinsicWidth`なのは左右方向に中央寄せしたかったからだ。
固定幅にするか自動で決めてもらうかで、ここは自動で決めてもらった。
一度描画計算するのでパフォーマンスは落ちるそうだ。

一番下を`Column`にすることでこのラジオボタンは縦並びになる。`Row`なら横並びだ。
